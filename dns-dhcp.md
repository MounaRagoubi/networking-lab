# DNS and DHCP Basics

## Objective

Understand the basic role of DNS and DHCP in a network.

## DNS

DNS translates domain names into IP addresses.

### Useful commands

```bash```

nslookup google.com

dig google.com


## DHCP
DHCP automatically assigns network configuration to devices, such as:
- IP address
- Subnet mask
- Default gateway
- DNS server

## Example
A DHCP server ca, assign addresses from :

````192.168.1.100```` to ````192.168.1.200````

with: 
- Gateway: ````192.168.1.1````
- DNS server: ````8.8.8.8````

## What I learned 
- The role of DNS in name resolution
- The role of DHCP in automatic IP configuration
- The difference between static and dynamic IP addresses
- How DNS and DHCP work together in a network
